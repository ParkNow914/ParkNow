# Contribuindo para o ParkNow

Obrigado por considerar contribuir para o ParkNow! 🎉

## Como Contribuir

### Reportando Bugs

1. Verifique se o bug já não foi reportado nas [Issues](https://github.com/ParkNow914/ParkNow/issues)
2. Use o template de bug report
3. Forneça o máximo de detalhes possível

### Sugerindo Melhorias

1. Verifique se a sugestão já não foi feita
2. Use o template de feature request
3. Explique claramente o benefício da funcionalidade

### Pull Requests

1. Fork o repositório
2. Crie uma branch para sua funcionalidade (`git checkout -b feature/AmazingFeature`)
3. Commit suas mudanças (`git commit -m 'Add some AmazingFeature'`)
4. Push para a branch (`git push origin feature/AmazingFeature`)
5. Abra um Pull Request

### Padrões de Código

- Use JavaScript moderno (ES6+)
- Siga as convenções de nomenclatura existentes
- Adicione comentários quando necessário
- Escreva testes para novas funcionalidades

### Commits

Use commits semânticos:
- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` documentação
- `style:` formatação
- `refactor:` refatoração de código
- `test:` testes
- `chore:` tarefas de manutenção

## Código de Conduta

- Seja respeitoso e inclusivo
- Aceite críticas construtivas
- Foque no que é melhor para a comunidade

## Dúvidas?

Abra uma issue ou entre em contato através do repositório.

Obrigado! 💙
